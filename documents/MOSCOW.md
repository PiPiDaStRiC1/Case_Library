# MoSCoW-анализ LibraFlow

## MUST — обязательно для MVP

- каталог книг, авторов и экземпляров;
- поиск по названию, автору, ISBN и теме;
- фильтр по филиалу и доступности;
- личный кабинет читателя;
- бронь доступного экземпляра;
- продление при отсутствии очереди;
- рабочее место библиотекаря: выдача, возврат, отмена брони;
- роли читателя, библиотекаря и администратора;
- импорт исходного фонда и журнал ошибок;
- email-уведомления о брони и сроке возврата;
- аудит изменения статусов экземпляров.

## SHOULD — желательно

- очередь бронирования;
- отчёты по выдаче, просрочкам и популярности;
- штрихкод или QR-код читательского билета;
- настройка правил по категориям читателей;
- напоминания за 1–3 дня до возврата;
- экспорт CSV.

## COULD — можно добавить

- рекомендации по истории выдачи;
- интеграция с внешним API карт для отображения филиалов;
- push-уведомления;
- мультиязычный интерфейс;
- карта филиалов и навигация;
- кабинет родителя для детского читателя.

## WON'T — не входит в текущую итерацию

- продажа книг и подписка на электронный контент;
- оцифровка и хранение защищённых копий книг;
- RFID-ворота и автоматизированные стеллажи;
- нативные приложения iOS/Android;
- межбиблиотечный абонемент;
- ML-рекомендатель и прогнозирование спроса.
